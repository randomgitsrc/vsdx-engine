# 观察：update 首次写回会改变容器高度

**2026-11-18 实测**

```
导出 → 只改一个节点文字 → update 写回
  容器高度 1.230 -> 1.610  (+0.38)
  容器中心 y 也偏移
节点位置、连线数、文本数均不变
连续 3 次往返后稳定在 1.610
```

## 事实

- 增量 `update` 首次写回，三个容器高度全部 +0.38
- 之后不再增长（稳定）
- 节点几何、连线、文本完全不变

## 未查明

`+0.38` 与推导公式 `top += heading(0.46)`, `bottom -= padBottom(0.22)` 的净增量 `0.24` 不符。
原始 `1.23` 的产生路径未追。

## 判断

**可能不是缺陷**：若 `1.23` 是布局时为容纳成员算出的紧贴值，
而 `1.61` 是加上 heading 与 padding 的"规范容器高度"，
那么首次写回是**修正**而非破坏——稳定不再增长也支持这一点。

**但需要证据**。已交给独立审查确认。
