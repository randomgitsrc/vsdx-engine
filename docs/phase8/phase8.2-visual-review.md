## 4. 这份记录的作用

**它是 Phase 8.2 的验收对照物。** 实施后重跑四张图，逐项对比：

| 项 | 修前 | 修后目标 |
| --- | --- | --- |
| 标题/副标题 | 重叠 | 分离且层级分明 |
| 容器色 | 全同 | palette 驱动，同层可区分 |
| 节点色 | 全白 | 角色色可辨 |
| 流程图顺序 | 颠倒 | `intake` 在最上 |
| 分隔线 | 穿字 | 不压文字 |

**验收方式：** 人工目视，不用分数。若修后分数提高但观感未变，视为未完成。
