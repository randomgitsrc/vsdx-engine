## 决策 1：R1 外部编辑能力受限 —— 有条件接受

**负责人意见：**

> 有条件接受外部编辑能力受限，但**绝不接受破坏原文件**。
> 先定位根因，尝试 OfficeIMO 上层修复和 OPC 局部修改。
> 如果无法保证保真，则对受影响的修改操作**安全拒绝**，明确返回能力限制。
> **不得静默生成可能损坏原图形的 VSDX。**

**落实方式：**

| 层次 | 做法 |
| --- | --- |
| 1 | 定位根因：`Save` 合成 vs 本写入器触发 |
| 2 | 优先尝试在 OfficeIMO 之上修复（保存后修正） |
| 3 | 其次尝试 OPC 局部修改（只改必要部件） |
| 4 | 两者都不行 → **拒绝执行**，返回明确的 `unsupported` / `degraded` 结果 |
| 禁止 | 静默产出可能已损坏的原图形 |

**对 8.1 的约束：** 这是 A 任务，必须先于任何图形对象扩展完成。

## 决策 2：FreePath 读回错误纳入 8.1

**负责人意见：**

> FreePath 读回错误必须纳入 8.1。创建、读取、编辑、保存、重新读取都要验证。
> 对暂不支持的 Geometry 指令**必须保留原始内容**，不能错误转换成普通 Rectangle。

**落实方式：**

- `FreePath` 类型在 8.1 实现（不是 8.3）
- 五环节验收：创建 → 读取 → 编辑 → 保存 → 重新读取
- **未知 Geometry 指令保留原文**（不解析、不丢弃、不降级为矩形）

**对 8.1 的约束：** C 任务，在 P0 与 ShapeOrder 之后。

---

## 决策 3：图片占位框不可作为 8.3 验收

**负责人意见：**

> 图片预览占位框**只允许作为阶段性限制**，不接受作为 Phase 8.3 最终图片支持的验收结果。
> 8.3 必须验证**真实图片嵌入、读回、替换和 Renderer 显示**。SVG 独立验证。

**落实方式：**

| 要求 | 验收标准 |
| --- | --- |
| 真实嵌入 | 真实 PNG/JPG 写入 `visio/media/` |
| 读回 | 模型能还原媒体引用 |
| 替换 | 增量编辑可换图 |
| **Renderer 显示** | 预览中**可见真实位图**，非占位框 |
| SVG | 独立验证（不并入图片验收） |

**已识别的新依赖风险：** Renderer 显示真实位图可能需要图像解码库
（SkiaSharp / ImageSharp / System.Drawing），需单独评估许可证与体积。
若无法在不引入重型依赖下实现，须向负责人报告后再决定。
