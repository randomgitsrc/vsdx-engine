## 四、这个实验证明了什么

**1. 文档结构是可修的瓶颈**

AT-2 失败不是 Agent 能力问题。同一类任务，把「选哪种格式」提到最前之后，AT-3 完成了。

**2. 之前「Agent 读了建议但没采纳」的判断是错的**

AT-2 的 Agent 很可能根本没走到 §5a。文档顺序决定了它用什么。

**3. 测量本身会改变行为**

AT-3 加的四条约束（预算、检查点、起点、探测上限）都是**写给 Agent 的指令**，
它们本身就是 AT-2 缺失的东西。

**所以 92 分不能全部归功于文档改动。** 一部分来自任务描述变清楚了。

### 关于第 2 条

Agent 说「一字未变」，我实测：

```
原: claim(2.1) underwrite(4.0) mq(5.8) payment(7.7) notify(9.5)
反: claim(2.1) mq(4.0) underwrite(5.8) notify(7.7) payment(9.5)
```

**位置确实变了**，分数 92→90。但 `claim` 仍在最左，主链顺序未变——
因为 `OrderWithinBands` 按图位置排序，`MinimiseCrossings` 按跨层边优化，
**数组顺序只在交叉数相同时才起作用**。

Agent 的观察方向对，结论过头了。已按实测修正后写入 `SKILL.md`。
